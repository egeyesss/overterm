## Agent brand marks

The files in `app/ui/src/brand/` are the logos of the tools OverTerm can
recognise. A tab draws one so you can tell at a glance which session is
which, and a tool with no mark falls back to a short text label.

The SVGs came from [@lobehub/icons](https://github.com/lobehub/lobe-icons),
which is MIT licensed. The gradient identifiers left inside the files
still name it. `antigravity.png` was added separately and its source is
not recorded here.

Each mark is a trademark of whoever owns it, among them Anthropic, OpenAI,
Google, Moonshot AI and Ollama. They appear here only to identify which
tool is running in a session. None of those companies endorse or sponsor
this project or are involved in it in any way.

If you own one of these marks and would rather it were not used here, open
an issue and it comes out. Losing one costs a tab its picture and nothing
else.
